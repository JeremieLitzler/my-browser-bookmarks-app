# A web app that saves all your browser's bookmark in one place

## Idea

I have bookmarks on my personal computers, using Chrome, on my smartphone, using the Ad blocker browser, and work computer, using Edge (company requirement).

But I don't want to export/import from a browser to another, so this app lets a user access his bookmarks from any browser, at any time. It is a single place to bookmark.

The features:

- [ ] Save bookmarks to a Supabase database
- [ ] Keep website private with Supabase Auth so you don't expose bookmarks
- [ ] Allow to import from a HTML file (generated by a browser bookmark export function) 
- [ ] Keep existing folders and subfolders organization from an HTML file
- [ ] Mark some bookmarks as public (visible without any auth) and other as private (require auth)
- [ ] Search bookmarks with minimal input
