# A web app that saves all your browser's bookmarks in one place

## Idea

I have bookmarks on my personal computers, using Chrome, on my smartphone, using the Ad blocker browser, and work computer, using Edge (company requirement).

But I don't want to export/import from a browser to another, so this app lets a user access their bookmarks from any browser, at any time. It is a single place to bookmark.

It starts as my own personal instance, but the app is built multi-tenant from day one so other people can sign up and get their own bookmark collection, in case it turns out to be something others want too.

## Stack

- Frontend: Vue 3, using the [VueSupabaseBoilerplate](https://github.com/JeremieLitzler/VueSupabaseBoilerplate) (Vue Router, Pinia, VeeValidate, Tailwind CSS + shadcn-ui, Vite)
- Backend: Supabase (Postgres database + Auth)
- Hosting: Netlify

See [`CONTEXT.md`](./CONTEXT.md) for the domain glossary (Bookmark, User, Folder, Import, etc.) referenced below.

## Features

- [ ] Sign up / sign in via magic link (email only, no password) using Supabase Auth, open to anyone from launch
- [ ] Each User's Bookmarks and Folders are private to them (multi-tenant from the start)
- [ ] Each User picks a Username, which addresses their own Public Page (e.g. `/u/username`)
- [ ] Mark a Bookmark as Public (shown on the owner's Public Page, no auth required) or Private (visible only to the authenticated owner)
- [ ] No directory or listing of Users/Public Pages — a Public Page is reachable only via a link its owner shares themselves
- [ ] Full in-app CRUD for Bookmarks: create, edit, delete
- [ ] Full in-app CRUD for Folders and Subfolders: create, rename, move, delete
- [ ] Import bookmarks from an HTML file (generated by a browser's bookmark-export function)
- [ ] Preserve the folder/subfolder structure from the imported HTML file, merging into existing Folders of the same name/path rather than duplicating them
- [ ] Detect duplicate Bookmarks on import, keyed on URL
- [ ] Queue Import Conflicts (incoming Title and/or Folder differs from existing) for review at the User's own pace — keep existing, take incoming, or (for Title) enter a different value
- [ ] Search bookmarks with minimal input: fuzzy match on Title and URL, starting from 2 characters typed
- [ ] Add a GDPR/privacy page disclosing what personal data is stored (email, Username)

### Later (v2)

- [ ] Companion browser extension for one-click bookmark capture, to fully replace native browser bookmarking
